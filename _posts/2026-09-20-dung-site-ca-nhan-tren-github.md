Dùng GitHub Page, tạo một file index.html đơn giản là đã có được một site rồi. 
Ngoài ra, nếu muốn có theme các kiểu thì kết hợp với Jekyll. 

Có thể dùng tên miền riêng, trỏ tới GitHub là được. 

Có thể tạo thêm các bài viết, viết theo kiểu Markdown (rất dễ).

Ngoài ra, nếu đã biết cách dùng Git và GitHub thì còn có thể tự lưu trữ và soạn thảo ở local, 
sau đó đồng bộ lên GitHub.

Chắc tôi chỉ viết như này thôi, không cần chi tiết quá. 
Bởi vì thời này, các công cụ Search và AI đều hỗ trợ rất nhiều rồi ;)
